## 五个行业信号（投递策略依据）

1. **Agent 基础设施成独立编制**：DeepSeek（弹性计算/沙箱）、Kimi（AgentEnv）、通义（Agent Infra 工程师）——容器/后端背景的新入口，竞争者少。
2. **"深度使用过竞品"成硬性加分**：DeepSeek JD 明写"Vibe Coding 重度用户"、要求用过 Claude Code/Manus——AI 工具重度使用经历要写进简历。
3. **评测/数据质量岗独立成序列**：四家有独立编制，门槛低于"数据算法"。
4. **替代性门槛明示**（通义）：顶会一作或开源核心贡献或竞赛，三选一，证据可核查。
5. **模型公司 vs 大厂**：模型公司现金高 20-50%、一人多能、偏好年轻；大厂体系化、细分深、对 30+ 社招友好。

## 投递组合模板

- **应届冲刺**：DeepSeek/Kimi 研究或工程（现金高、扛核心）+ 通义/智谱校招（HC 多）做匹配档 + 大厂 AI 岗保底
- **社招 infra**：MiniMax/Kimi（45-100K 带宽）冲刺 + 通义百炼/PAI 匹配 + 大厂 infra 保底
- **转行**：先看"新入口方向"（Agent infra/沙箱、Agent 评测）的模型公司岗 + 数据工程线；30+ 避开模型公司研究岗
- **实习切入**：MiniMax Top Talent（1000-2000 元/天）、智谱量化/评测实习、Kimi"穿越计划"（转正发期权）

## 面试特色速览（模拟面试时叠加）

- **DeepSeek**：第一性原理推导，追问深；开源组件（3FS/DeepEP/DSec）设计可能被问
- **MiniMax**：不考八股，深挖自研核心技术（Lightning Attention 原理级）
- **智谱**：算法岗必问数据构建（构造/筛选/合成）
- **通义**：研究岗核可核查证据；平台岗问 MaaS/推理服务设计
- **Kimi**：长上下文与 agent 技术底色（MoonEP/FlashKDA/AgentEnv）
