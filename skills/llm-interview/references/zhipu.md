# 智谱（Zhipu AI / GLM）求职指南

## 公司招聘画像（截至 2026-10-06）

- **渠道**：zhipu-ai.jobs.feishu.cn（社招）+ 校招子站（zhipucampus）；"47 个热招岗"持续在招；校招走"智谱星计划"。
- **组织特色**："AI院-GLM团队-岗位"三级命名；**算法岗把数据构建写进职责**（算法+数据一体是智谱特色）；评测、量化都有独立实习编制。
- **清华系权重的真相**：JD 本身只写"博士学历优先、C/C++/Python"，不限院校（校招实际覆盖北语等高校）；但创始团队全出清华 KEG（唐杰/张鹏/刘德兵），媒体称算法部门"几乎清一色清华人"，网传"非清华系别去实习"——文化层面存在偏好，硬背景不强者建议主投工程/infra 线。
- **薪资**：分层清晰——后训练算法 30-60K·16 薪；数据质量方向 45-75K；Coding Agent 后训练 60-90K；多模态 1-3 年 40-60K×16（知乎面经）；六险一金+算力资源。

## 技术底色（面试准备）

- **数据构建是算法岗必问项**："对齐数据的质量和多样性怎么保证""数学/代码数据怎么构造、筛选、合成"——准备一条数据闭环故事线（同通用数据岗，见 ai-infra-interview-coach 的 llm-data.md 题库）。
- GLM 产品线关键词：GLM-5/5.3（744B、200K 上下文、1M Agent 上下文）、Agentic GLM 战略、CogVideo、CodeGeeX——投 Agent 相关岗要聊 GLM 的 agent 路线。
- 战略背景：50 亿美元融资投向**训练数据、任务环境、芯片适配**（自训练体系）——数据与 infra 是扩张主线，也正是招聘重心。

## 独特关键词

AI院-GLM 团队、数据构造/筛选/合成、数学/代码预训练数据、超长上下文、低比特量化（PTQ/QAT）、GLM-Platform、Agentic GLM、智谱星计划。

## 投递建议

- 数据方向求职者：智谱把数据质量/数据处理独立成序列（45-75K），是数据背景的好标的；校招后训练岗专设对齐数据职责。
- 工程线（训练/推理 Infra、平台）：清华偏好弱于算法线，且校招推理 Infra 岗只要求基础（C++/Python+OS），应届工程背景可投。
- 想要编制化实习：量化、评测都有专门实习岗——比"打杂实习"含金量高，转正路径清晰。
- 清华系/学术背景强：算法线文化契合度高，可直接冲预训练/评测岗。
