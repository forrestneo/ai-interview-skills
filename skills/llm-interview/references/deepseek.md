# DeepSeek（深度求索）求职指南

## 公司招聘画像（截至 2026-10-06）

- **官网**：talent.deepseek.com（JS 渲染，岗位经快照/媒体交叉）；7 大类：全栈开发/算法、AI 核心系统研发、运维、产品、模型数据策略、深度学习研究员、职能。Base 北京/杭州。
- **2026 三轮扩招**：3-25 放出 17 个 Agent 岗（算法/数据评测/基建全链条）；6-25"所有部门规模扩大至少一倍"（7 类 33 岗）；**9-08 约 150 个名额"史上最大招聘"——全部工程岗、0 研究岗，面向 2-10 年资深工程师**；10-03 弹性计算团队（DSec）再放 HC。
- **偏好**：年轻（应届优先）+竞赛背景（高中/大学出成绩）+顶会论文；"让新人直接承担最核心的工作"，梁文锋亲自参与面试。**警示案例**：华为首届天才少年李博杰（34 岁，SIGCOMM/SOSP/NSDI 多篇）面试受挫——资深空降不占优，30+ 慎投研究岗。
- **薪资**（媒体/平台口径）：深度学习研究员 50-80K×14 薪；全栈开发约 36 万/年起；AGI 研究员应届最高超 120 万/年；"年薪 200 万上限"系媒体汇总未经官方确认。

## 独特 JD 关键词（简历适配用）

"Vibe Coding 重度用户"（全栈岗硬性倾向）、"深度使用过 Claude Code、OpenClaw、Manus"（产品岗）、MCP / Tool Use / Function Calling、跨 session 记忆连续性、数据-训练-评测闭环、Agent Harness、DSec、3FS/DeepEP（开源 infra 背景加分）。

## 技术底色（面试准备方向）

- 开源 infra 组件是理解其团队的钥匙：3FS（存储）、DeepEP/DeepGEMM/FlashMLA（通信/算子）、DSec（沙盒：日服务 300 万沙盒、峰值 38 万并发，3FS+MicroVM/EROFS+AppArmor/eBPF 隔离）——面 Agent 基建岗要能聊容器隔离与调度；面存储岗要读过 3FS 论文。
- 面试风格：偏好第一性原理推导、追问深（与"让新人扛核心"文化一致）。

## 投递建议

- 应届硕士+竞赛/论文：直接投研究员/研发工程师，最年轻时的最优选择之一（现金高+核心任务）。
- 2-10 年工程师：9 月型工程 HC 是主窗口（API/数据工程/线上服务），关注官网节奏。
- 容器/后端背景：Agent 弹性计算与 Agent infra 岗是新入口，竞争者少。
- 30+ 资深：工程岗可投（9 月批即面向资深），研究岗慎重。
